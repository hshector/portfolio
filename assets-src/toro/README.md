# El toro

«bull walk cycle», de Lucy Greenhill (https://sketchfab.com/Leafalu), descargado de
https://sketchfab.com/3d-models/bull-walk-cycle-d59e56bc90a34bcd826d02798a54ac96
con licencia CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Permite uso comercial y
modificaciones si se cita a la autora; el crédito está en la web, bajo la isla.

Cambios: recoloreado en negro (en el material, al cargarlo), trote y galope derivados de su ciclo
de paso (src/island/gaits.ts) y comprimido con `scripts/assets/toro.sh`.
